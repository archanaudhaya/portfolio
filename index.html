Selected Projects

FINAL YEAR PROJECT

R-GUARD

Ransomware Defense System using Heuristic Traps and Behavioural Anomaly Detection

PROBLEM

Modern ransomware rapidly encrypts files, while traditional antivirus solutions can fail to detect new variants because they rely heavily on malware signatures.

IMPLEMENTATION

Monitors real-time file-system events and extracts entropy and behavioural features using:

LSTM Sliding Window Approach UA-DES-DBN DBSCAN Random Forest Gradient Boosting
SOLUTION

Aims to detect ransomware at an early stage, generate risk-based alerts, and help prevent large-scale file encryption and data loss.
